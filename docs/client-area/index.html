The project

WordPress CMS (OS-021) makes a WordPress instance operable via an agent. WordPress is the CMS binding; the agent loop is WordPress Studio + WP-CLI / MCP skills; client edit prefers ACF Local JSON over the Site Editor. Fronts pull OS-000 tokens — sites are theme-neutral plus their own brand, not OGANIKO green.

This Client Area is the single place where instance admin access and configuration surfaces come together. Each area has its own tab. Where a WordPress site is linked, panels fill from the snapshot; until then, spaces are reserved.
