The project

WordPress CMS (OS-021) makes WordPress instances operable via an agent. WordPress is the CMS binding; the agent loop is Docker / Studio + WP-CLI; client edit prefers ACF Local JSON over the Site Editor. Fronts pull OS-000 tokens — sites are theme-neutral plus their own brand, not OGANIKO green.

This Client Area is the single place where instance admin access and configuration surfaces come together. Switch instances in the header. Where a WordPress site is linked, panels fill from that instance's feed; stubs stay marked not connected yet.
